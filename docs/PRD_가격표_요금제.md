### 2.1 크레딧 패키지

| 패키지 | package_type | 가격 | 크레딧당 단가 | 할인율 | 비고 |
|--------|-------------|------|-----------|--------|------|
| **무료** | - | 0원 | - | - | 회원가입 시 1회 자동 지급 (기본 분석) |

### 2.2 분석 종류와 크레딧 차감 (2026-10-06~)

| 분석 종류 | 모델 | 차감 | 비고 |
|------|------|------|------|
| 기본 분석 | Claude Sonnet 5.5 | 1크레딧 | 기본값 |
| 정밀 분석 | Claude Opus 5.5 (effort high) | 2크레딧 | 분석 설정 단계에서 선택 |
| 1단계 문서 스캔 (직군·키워드) | Claude Haiku 4.5 | 0 | 크레딧 차감 없음 |

**쪽수 추가 차감 (2026-10-07~)**: 40쪽까지는 위 차감만, 그 뒤 40쪽마다 +1크레딧 (1~40쪽 +0 · 41~80쪽 +1 · 81~120쪽 +2 … 300쪽 상한 +7). 기본·정밀 모두 같은 추가분.
- 쪽수는 서버가 PDF 원본에서 직접 센다(`pdf-parse`). 그 외 형식은 추출 텍스트의 쪽 표지로 판정
- 기준값·안내 문구: `lib/analysis/pages.ts` (`PAGES_PER_CREDIT`, `LARGE_DOC_NOTICE`)

코드: `lib/analysis/model.ts` `MODEL_TIERS[tier].creditCost` + `lib/analysis/pages.ts` `extraCreditsForPages`, 차감은 `subscription.ts:deductCredit(amount)`.

### 2.3 크레딧 규칙
- 크레딧 만료 없음 (영구 유효)
- 회원가입 시 `analysis_credits = 1` (첫 1회 무료)
- 정밀 분석은 보유 크레딧이 2개 이상일 때만 선택 가능 (서버 가드 `analyze.ts:guardAnalysisEntry(creditCost)`)
- **일일 분석 상한: 계정당 24시간 5회** (서버 강제, 관리자 제외)
- 부분 환불 시 사용분 차감 단가 = 결제 당시 정가. 2026-10-06 이전 주문(1회 2,900 / 5회 7,900 / 10회 12,900원)은 2,900원 적용 (`unitPriceForOrder`, 금액+크레딧 수로 판별)

### 2.4 원가 참고 (2026-10-07 실측 — 합격 문서 9건 테스트, `docs/REPORT_2026-10-07.md`)
- 기본 분석 1건 287~658원 (평균 약 450원, 4~44쪽 문서), 정밀 분석 약 1,060원
- 30크레딧 실수령 크레딧당 약 1,310원 → 기본 분석 마진 50~66%. 손익 바닥선은 크레딧당 판매가 약 750원
- 무제한 구독(옛 월 13,800원, 실수령 약 12,100원)은 기본 분석 18~27회, 정밀 11회부터 적자

### 2.4.1 원가 참고 (2026-10-06 추정)
- 실수령 = 결제액 × 약 87% (부가세 10% + PG 수수료 약 3.5% 차감 가정)
- 기본 분석(Sonnet 5.5) 1건 원가: 약 630원 추정 → 10크레딧 기준 크레딧당 실수령 1,739원, 마진 약 64%
- 정밀 분석(Opus 5.5) 1건 원가: 약 1,500원 추정 → 2크레딧 실수령 3,478원, 마진 약 57%
- 가정 근거와 손익분기 계산: `TASK_서비스개선_2026-10.md` 5장

## 5. 가격 변경 절차

```
1. 이 문서(PRD_가격표_요금제.md) 먼저 수정
2. app/actions/payment.ts의 CREDIT_PRICES / SUBSCRIPTION_PRICES 수정 (서버 기준값)
3. 위 4.1~4.3 표의 모든 파일에서 UI 가격 수정
4. 테스트: 결제 페이지에서 실제 금액 확인
5. 커밋 & 배포
```

> ⚠️ **주의**: 서버(payment.ts)와 UI 가격이 다르면 결제 오류 발생.
