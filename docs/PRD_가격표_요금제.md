## 2. 크레딧

### 2.1 크레딧 패키지

| 패키지 | package_type | 가격 | 크레딧당 단가 | 할인율 | 비고 |
|--------|-------------|------|-----------|--------|------|
| **무료** | - | 0원 | - | - | 회원가입 시 1회 자동 지급 |
| **1크레딧** | `credit_1` | 2,900원 | 2,900원 | - | 기본 단가 |
| **5크레딧** | `credit_5` | 7,900원 | 1,580원 | 45% | - |
| **10크레딧** | `credit_10` | 12,900원 | 1,290원 | 55% | 월 구독보다 1,000원 저렴 |

### 2.2 크레딧 규칙
- 크레딧 만료 없음 (영구 유효)
- 분석 1회 = 크레딧 1개 소모
- 회원가입 시 `analysis_credits = 1` (첫 1회 무료)
- **일일 분석 상한: 계정당 24시간 5회** (서버 강제, 관리자 제외 — `analyze.ts:guardAnalysisEntry`)

### 2.3 원가 참고 (2026-08-05 기준)
- 분석 1건 원가: 약 400~500원 (Claude Sonnet)
- 1크레딧 2,900원 = 원가율 약 15% / 10크레딧 1,290원 = 약 35%

## 3. 1:1 과외 (메인 수익원)

| 항목 | 내용 |
|------|------|
| 가격 | **비공개 — 상담 후 안내** |
| 상담 | 오픈카톡 https://open.kakao.com/o/sLz0kgBf (`lib/tutoring-config.ts`) |
| 결제 | 사이트 밖 (계좌이체 등) — PG 미사용, 심사 이슈 없음 |

## 5. 가격 변경 절차

```
1. 이 문서(PRD_가격표_요금제.md) 먼저 수정
2. app/actions/payment.ts의 CREDIT_PRICES / SUBSCRIPTION_PRICES 수정 (서버 기준값)
3. 위 4.1~4.3 표의 모든 파일에서 UI 가격 수정
4. 테스트: 결제 페이지에서 실제 금액 확인
5. 커밋 & 배포
```

> ⚠️ **주의**: 서버(payment.ts)와 UI 가격이 다르면 결제 오류 발생.
